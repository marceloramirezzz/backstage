# SidebarNav

The app's left rail: Create button, `bs-over` group labels, and `bs-nav` links with 16px icons.

- The current page link gets `aria-current="page"` (spotlight tint, label and edge marker).
- Top-level destinations mirror the domain: Calendar, Repertoire, Setlists, Dashboard, Payouts, Members, Landing page.
- Hide links a role can't use rather than disabling them.
- The brand lockup (`bs-brand`) sits at the top: door mark + "Backstage" in `body-strong` weight. Include both mark images (`bs-logo-on-dark`, `bs-logo-on-light`); the theme shows the right one.
