# Input

Text inputs and selects: `bs-field` wraps `bs-label`, the control (`bs-input` / `bs-select`) and an optional `bs-hint`.

- Labels are always visible, sentence case; placeholders show an example, never the label.
- Error: add `is-error` to the field and put the message in the hint.
- `bs-select-pill` for toolbar filters (Month, Year).
