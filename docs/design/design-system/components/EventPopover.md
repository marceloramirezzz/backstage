# EventPopover

The quick view that opens from an EventChip: actions bar, title, date/time and venue, then label/value rows.

- Rows are a `<dl>` of `bs-row`; show Pay only to roles with "see total pay & expenses".
- Amounts in Guaraníes, set in `num` (mono): `Gs. 4.500.000`.
- Close on Escape and outside click; return focus to the chip.
